Human-mediated integration · v0.1

Sometimes the integration you need is a copy button.

A deliberately low-tech pattern library for turning application state into portable, inspectable context for any LLM. No API required. No provider SDK. The human remains the transport and approval boundary.

Pattern library

Small patterns. Surprisingly useful workflows.

Each pattern uses the same transport. What changes is the transformation, scope, and contract around it.

01 / STATE → MARKDOWN

Context Offboard

Package the current project, case or screen into a clean, human-readable brief.

02 / STATE + TASK

Prompt Offboard

Add an explicit job to the context: critique this, explain it, find holes, plan next actions.

03 / CURRENT VIEW ONLY

Selection Offboard

Copy only what the person has filtered, selected or focused — not the whole application.

04 / SCHEMA → JSON

Typed Offboard

Use structured JSON when downstream interpretation needs stable field names or re-import later.

05 / COPY + DESTINATION

Copy + Open

Copy first, then open the user's chosen LLM. Still manual. Still visible. Just one less step.

06 / EXPORT ↔ IMPORT

Roundtrip Offboard

Ask the model to return a known schema, then validate and import it back into the originating tool.

Read contract
07 / TWO PEOPLE → TWO JSONS → ONE BRIEF

Meeting Brief Relay

Give both people the same prep pack. Each uses their own LLM and returns structured JSON. An orchestrator preserves shared ground, differences and unresolved questions.

Progressive integration

            
Use the smallest rung that works.

          

          
Clipboard offboarding is intentionally near the bottom of the ladder. That is a feature, not an embarrassment.

        


        

          
Clipboard
Visible, manual, provider-agnostic. Good for low-frequency handoff and prototypes.

          
Deep link
Copy + open a destination. Still human mediated.

          
API
Automated transport with credentials, lifecycle and error handling.

          
MCP
Model-visible tools and resources with an explicit capability surface.

          
Agent
Persistent orchestration, authority, policy and evaluation become first-class concerns.

        


        

          Rule of thumb: if a person needs the handoff occasionally and should inspect the context anyway, a clipboard boundary can be the more honest architecture.
        


        
import { offboard, composePrompt } from "./src/offboard.js";

await offboard({
  payload: appState,
  transform: state => composePrompt({
    context: state,
    task: "Find contradictions and propose next actions.",
    output: "Observations, missing evidence, risks, next actions."
  })
});
