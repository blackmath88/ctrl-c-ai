01 · CONTEXT OFFBOARD Fictional product: Museum Night Shift Console

The mummy moved. Probably HVAC.

A museum guard has a gloriously boring incident console. Instead of integrating an AI assistant into the security system, the console turns the current incident into a clean Markdown handoff.

ARCHEOLOGY_WING / INCIDENT 23:47● local only

sensor Motion detected in Gallery 4

camera No person visible

note Linen display moved ~2 cm

guard "I blame the vent, not Tutankhamun."

Shift handoff

Packages only this incident, not the entire museum log.

02 · PROMPT OFFBOARD Fictional product: Crumb & Consequence

The croissant is fine. The sign is not.

A bakery already knows today's product, price, audience and tone. The button adds one cognitive job: rewrite the chalkboard copy without turning sourdough into a "journey".

TODAY'S SPECIAL
Burnt Honey Croissant4.80

Current sign: "Indulge in an artisanal moment of flaky excellence."

TASK → Make it sound like a human bakery. Dry wit welcome. No "elevated", "journey", or "crafted with passion".
03 · SELECTION OFFBOARD Fictional product: Terminal 9 Lost & Found

Please identify the least plausible owner.

The app has 842 objects. The human filtered to three weirdly similar black umbrellas. Only the current selection should cross the boundary.

Lost & Found / umbrellas / black / mildly cursed3 selected
842 total records remain blissfully uninvolved.
04 · TYPED OFFBOARD Fictional product: Plant Clinic 3000

Your fern has symptoms. Your LLM gets a schema.

The plant app does not dump prose. It emits a small typed record with explicit fields so the next system can reason without guessing what "sad" means.

SPECIMEN F-019Boston fern
LEAFbrown tips
SOILdamp
LIGHTnorth window
OWNER THEORY"dramatic personality"

  "schema": "plant-clinic/triage/v1",
  "symptoms": ["brown tips"],
  "soil": "damp",
  "light": "north",
  "question": "rank likely causes"
}
05 · COPY + OPEN Fictional product: Small Town Radio Desk

Copy the bulletin. Then choose your accomplice.

The desk prepares a presenter brief, copies it first, and only then opens the model the editor wants. No silent handoff; no provider marriage.

88.4 FM
17:00 bulletin

Bridge closed for goats · school fête moved indoors · mayor insists the goose is "not an official mascot".

06 · ROUNDTRIP OFFBOARD Fictional product: Bug Laundry

Send bugs out dirty. Bring them back sorted.

The app exports three messy bug reports plus a return contract. The model returns structured triage JSON. The app validates it before anything touches the board.

07 · MEETING BRIEF RELAY Fictional product: Treaty Table

The cactus has become an organisational issue.

Lina wants the office cactus near the window. Max says the window is his "deep-work zone". Both get the same prep pack, answer privately with their own LLM, then an orchestrator builds the brief without pretending they agree.

08 · RATE + COMMENT FEEDBACK LOOP Fictional product: Name-O-Matic Deluxe

Don't write a better prompt. Point at what you like.

The model proposes names. The human reacts to concrete examples. Ratings plus reasons become the next prompt. Preference becomes state instead of vibes.

Progressive integration

Use the smallest rung that works.

Clipboard offboarding is intentionally near the bottom of the ladder. That is a feature, not an embarrassment.

Clipboard

Visible, manual, provider-agnostic.

Deep link

Copy + open a destination.

API

Automated transport with credentials.

MCP

Explicit model-visible capability surface.

Agent

Persistent orchestration and authority.

Escalation rule: when the clipboard starts feeling ridiculous at your actual scale, congratulations — you have evidence for a deeper integration.
