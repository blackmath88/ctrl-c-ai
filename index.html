Integration ladder offboard.js

Human-mediated integration · v0.2

Sometimes the integration you need is a copy button.

A deliberately low-tech pattern library for turning application state into portable, inspectable context for any LLM. Eight patterns, each shown on a fictional product with a working clipboard action and an inspector showing exactly what leaves the page. The products are invented; the workflows are not.

01 · Context offboard Fictional product: Museum Night Shift Console

The mummy moved. Probably HVAC.

A museum guard has a gloriously boring incident console. Instead of integrating an AI assistant into the security system, the console turns the current incident into a clean Markdown handoff.

08 · Rate + comment feedback loop Fictional product: Name-O-Matic Deluxe

Don't write a better prompt. Point at what you like.

Progressive integration

Use the smallest rung that works.

Clipboard offboarding is intentionally near the bottom of the ladder. That is a feature, not an embarrassment.

Clipboard

Visible, manual, provider-agnostic.

Deep link

Copy + open a destination.

API

Automated transport with credentials.

MCP

Explicit model-visible capability surface.

Agent

Persistent orchestration and authority.

Escalation rule: when the clipboard starts feeling ridiculous at your actual scale, congratulations — you have evidence for a deeper integration.
